# REHAB26 首轮按人测试实验结果

实验日期：2026-11-09。所有结果来自实际训练与未见参与者测试；单随机种子的探索性基线，不是临床验证。

## 实验协议

肩外展与肩后伸分别预测五种错误，目标为主要及附加错误的并集。正确动作的五个标签均为零。

共 1111 次物理动作、3333 个单摄像头观察。每个观察独立输入模型；没有把多相机预测融合成更容易的测试任务。5轮轮流留一人测试，另1人验证，余下3人训练；同一人的所有动作与视角同组。

输入为已知起止帧内的三维骨架，按髋中点平移、躯干尺度归一化并重采样为96帧，不旋转身体。类别阈值和TCN早停只依赖验证者。没有将参与者、身体朝向、正确性或帧区间元数据作为模型特征。

具体结构、超参数、扰动、划分、阈值和可靠性规则见训练前固定的 `experiments/rehab26_v1/protocol.json`。完整模型、日志、预测与输入哈希保存在本地 `runs/rehab26_v1_20261109_cpu/`。

## 本轮能得出的结论

模型与权重已经实际得到，但当前误警和跨人变化较大，不能把这些模型当作已经可靠的康复警示系统。下面的数值是全部预定配置的探索性比较，不能按测试结果挑一个模型后再把同一测试集当作独立最终验证。

- ex1 本轮汇总宏F1最高的配置为角度统计＋逻辑回归（0.443），其正确动作误警率仍为47.7%。TCN坐标→加角度→再加可见度为 0.297 → 0.409 → 0.373，不能认定附加特征有一致收益。始终不报错的参考策略宏F1为0、标签集合全对率为50.0%；本轮模型的集合全对率也说明，不能只展示识别成功案例。
- ex7 本轮汇总宏F1最高的配置为角度统计＋随机森林（0.489），其正确动作误警率仍为43.3%。TCN坐标→加角度→再加可见度为 0.469 → 0.469 → 0.484，不能认定附加特征有一致收益。始终不报错的参考策略宏F1为0、标签集合全对率为50.1%；本轮模型的集合全对率也说明，不能只展示识别成功案例。

可靠性规则的跨人失败尤其需要注意：例如，若某折在验证者上达到预设要求，测试者上的保留预测仍可能大量出错。逐折覆盖率与保留指标见后表，不通过提高拒绝比例掩盖原始成绩。人工扰动下某些弱模型F1持平或略升，也不构成鲁棒性已经得到证明。

## 失败案例与交付边界

本地 `analysis/failure_cases.csv` 为每种动作/模型保留最多10个较高阈值距离但判断错误的动作，并保留骨架来源、帧区间、真值、预测、视角与可见度。每组按动作去重，适合后续人工检查；它不是随机错误率估计。

已完成：样本制作、5轮划分、50组实际模型拟合、权重保存、验证阈值选择、未见参与者测试，以及预先指定的输入消融和人工扰动诊断。没有根据测试结果重新选择参数。

尚未完成：多随机种子确认、真实视频对齐、RGB上传与自动分段、专家复核的提示映射、真实患者和临床验证。当前推理需提供一次完整动作的起止帧。三种TCN输入的差异只能作为初步消融观察，不能凭单个种子认定方法创新或稳定收益。

训练及逐折评估计时总和约 3.3 分钟（不含依赖安装、样本制作与报告生成），使用CPU。环境版本见本地 `environment.json`。
