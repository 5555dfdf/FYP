# 现有成果与证据边界

整理日期：2026-11-08。此文件记录已经产生的材料，与未来研究建议分开。模型训练和基线复现均未完成。

## 1. IRDS 数据审计：已完成

完成于 2026-10-17。原始骨架仅在本地，仓库保存脚本、派生统计和图表。

| 成果 | 证据/文件 | 能支持什么判断 |
|---|---|---|
| 全量读取与格式核查 | [audit_irds.py](../IRDS/analysis/audit_irds.py)、[汇总](../IRDS/analysis/audit_summary.json) | 2,589 次动作可读取；75 坐标列；RawData 与 Simplified 对应 |
| 每次动作的检查记录 | [sample_manifest.jsonl](../IRDS/analysis/sample_manifest.jsonl) | 可追溯人 ID、动作、标签、体位、帧数和跟踪/时间检查；不是训练/测试划分 |
| 数据分布图 | [data_overview.png](../IRDS/analysis/data_overview.png) | 类别、体位、人群和时长分布 |
| 实际动作示例 | [shoulder_examples.png](../IRDS/analysis/shoulder_examples.png)、[样本测量](../IRDS/analysis/visualized_samples.json) | 同人同体位的正确/错误骨架与几何角度观察 |
| 原论文与本地数据综合评估 | [IRDS_assessment_zh.md](../IRDS/analysis/IRDS_assessment_zh.md) | 可研究范围、异常、评价设计及补标签条件 |

关键结果：标签 1/2 共 2,577 次，其中正确 2,047、错误 530；另有 12 条特殊标签。论文说 29 人，本地有 30 个唯一 ID；额外 ID 217 身份尚不清楚。530 次错误中 523 次来自 2xx ID。肩部动作名与原始关节左右命名存在系统性对应差异。

这些发现支撑使用按人评价、患者子集与体位分析，也说明不能把所有动作随机打散后以高准确率证明泛化。原始跟踪质量和时间字段仍需用于后续预处理。

**图表与角度是探索结果。** 示例不是显著性检验，几何角度不是经过验证的临床测角结果，530 次错误也不等于 530 名独立患者。

## 2. IRDS 后续研究调研：已形成记录

完成于 2026-10-17，见[后续训练与评估调研](../IRDS/IRDS_followup_literature_review_zh.md)。记录八项实际使用 IRDS 的工作及其任务、方法、划分和阅读层级，还指出一项数据集描述与原始 IRDS 冲突的论文。原文与实现的核对深度不同，不等于全面代码审计。

直接得到的认识包括：整体正确性训练已有先例；分割/计数指标不能当成分类指标；样本随机划分和按人测试不能直接比较；注意力图不自动验证错误原因。

## 3. 扩大调研：已整理 33 篇候选

完成于 2026-11-06，包含综述、多个数据源、时序/骨架模型、对比学习、迁移学习和评价协议。

- [论文比较表](../literature/2026-11-06/paper_matrix_zh.md)：人可读的阅读状态和研究用途。
- [结构化登记](../literature/2026-11-06/paper_registry.json)：DOI、作者、题名、年份、证据等级与笔记。
- [数据集比较](../literature/2026-11-06/dataset_comparison_zh.md)：标签、规模、获取状态和局限。
- [阅读记录](../literature/2026-11-06/review_memo_zh.md)：代表论文的具体判断与下一步。
- [本地证据索引](../literature/2026-11-06/source_inventory.json)：已保存来源文件的大小、哈希和对应论文信息，便于核对本地副本。

33 篇包含先前已涉及的文献；它们不是全部全文精读。另查得的补充线索未为了凑数纳入核心登记。这一轮是目的性扩展检索，不称为预注册系统综述。

值得保留的结果：KIMORE 有总分与分项；KERAAL 有细粒度错误标签但大量记录未标注；REHAB24-6 原始存储库列有 1,072 次重复的正确性和分段标签；FineRehab 官方页在当时仍写即将发布；同名数据在不同方法中可能有不同样本版本、评分尺度和标签定义。
