# 当前研究问题与后续实验

更新：2026-11-10。当前主线已收敛到REHAB26两种肩部动作的跨人五错误识别。下面是基于已完成实验的后续安排，尚未执行；实际已完成配置与成绩见[最佳设定](../experiments/rehab26_fusion_v3/BEST_SETTINGS_zh.md)。

## 1. 等权融合收益是否稳定

肩后伸等权融合+参考Transformer取得0.734，但只有一个种子；三种子概率融合Transformer为0.690±0.029。先固定参考网络、输入和划分，再补足种子，报告逐人/逐类、误警与漏警。不要将单种子最高值直接当成稳定优势，也不继续用这五人的测试成绩筛选新配置。

## 2. 难类与骨架质量

按预先固定的抽样方式复核耸肩、屈肘等错误、附加标签和低可见度关节，比较失败是否与姿态估计、标签含义或特征表达有关。visibility是估计器输出，不是坐标误差真值。当前加权融合没有一致优于等权，先查原因，再决定是否设计质量权重或扰动训练。

## 3. 三视角对齐的影响

当前使用动作进度重采样与每路固定yaw；没有精确时间戳和相机标定。后续若研究阶段对齐，先在训练/验证范围固定规则，保留真实躯干倾斜与动作内旋转，比较几何轨迹与分类结果。没有标定或三维真值时，不将分类F1改善解释成三维重建精度改善。

## 4. 跨人泛化与警示

五名志愿者和模拟错误限制泛化判断。优先获得兼容的新受试者确认，继续保留角度RF/TCN对照，分别报告正确动作误警和错误动作无警。若研究阈值校准或拒判，另行固定方案并报告覆盖率。SVG示意可用于说明错误类型；RGB提取、预测回放与专家提示映射仍是后续开发。

## 早期数据集与路线比较（2026-11-08历史快照）

以下记录选型时的问题和建议，不表示当前仍未确定数据集，也不表示同时推进所有路线。原始文献登记和获取状态保留在[2026-11-06调研](../literature/2026-11-06/review_memo_zh.md)与[数据集比较](../literature/2026-11-06/dataset_comparison_zh.md)；状态应按该日期理解。

### 目标与选择原则

最终尽量基于公开数据训练或微调出一个模型，提供权重、配置、可靠测试和推理入口。2026-11-08选型时尚未限定身体部位或设备配置；选择应由预测目标、可用标签、数据获取与可检验的问题共同决定。

以下是**研究假设和待做实验**，不是已有训练成果，也不是已确认的创新点。优先级表示应该先查什么证据，不表示已经选定课题。

### 方向 1：对新受试者可靠的动作正确性评估

**研究问题：** 在没有见过的受试者上，模型能否检出错误动作？引入骨架表示之后，是否确实超过仅凭时长或简单几何特征的预测？

**数据与已有基础：** IRDS 原始骨架已完成全量审计，标签 1/2 有 2,577 次，其中错误 530 次。错误高度集中于部分人；体位与人群相关。REHAB24-6 可作为第二候选，但尚未读取动作数据。先比较全动作与部分动作的有效标签分布，再决定身体部位。

**相关工作：** [旋转不变骨架评估](https://doi.org/10.1109/TNSRE.2023.3282675)、[IRDS 防泄漏基准](https://doi.org/10.3389/fmed.2026.1878438)、[Rehab-Pile](https://doi.org/10.1109/FG67764.2026.11556986)。因此“首次用 IRDS 训练分类器”不能作为贡献。

**最小可检验实验：** 固定按人的外层划分，比较多数类、仅帧数、几何特征模型、轻量 TCN/GRU 和一个骨架网络。所有阈值、归一化、早停与参数选择都在训练部分完成。以错误为阳性，报告错误 precision/recall、macro-F1、balanced accuracy、混淆矩阵和按人结果。

**可能进一步深入的问题：** 类别不平衡；模型校准/拒判；跟踪质量对预测的影响。每次只选择一个问题深入，并用无该组件的模型作对照。

**启动前核对：** ID 217 的不确定性、左右语义和患者子集定义；若身份不能确认，需要显式保留限制并预设敏感性分析。**收缩条件：** 如果改善完全来自时长或少数人的表现，暂不声称学会姿态纠错或可泛化到真实患者总体。

### 方向 2：具体错误类别识别，逐步走向可验证反馈

**研究问题：** 能否从动作序列预测具体错误，而不止给出整体错误？联合学习部位或时间信息能否提高错误类别识别？

**数据依据：** KERAAL 原论文和作者说明包含整体正确性、错误类别、出错身体部位和时间窗，且部分记录未标注。UCDHE 相关数据在 Rehab-Pile 中也有含正确类的多类错误任务，但原始标签与来源还需追溯。

**相关工作：** [KERAAL 数据库](https://doi.org/10.1109/IJCNN60899.2024.10650036)、[2025 错误分类 Transformer](https://doi.org/10.1109/ICORR66766.2025.11063192)。错误分类已有研究，尚需全文比较其标签、划分和训练策略。

**最小可检验实验：** 先解析标注并生成“人 × 动作 × 错误”的计数，确认是否多错误共存。以简单时序分类器对比骨架/Transformer，先完成按人错误分类；标注足够时再增加部位或时间输出，比较单任务和联合学习。

**可形成的贡献候选：** 在相同按人协议下验证少标注错误识别；用原始位置/时间标签评估反馈，而不仅展示注意力图。这些需在充分阅读后核对是否已有相同实验。

**启动前核对：** 2,622 总记录不等于 2,622 完整标注样本；需确认已标注患者、各错误支持人数、标签重叠和时间单位。**收缩条件：** 稀有错误只出现在一两人时，缩小类别范围或只研究整体正确性，不人为制造“泛化成功”的测试协议。

### 方向 3：总体评分与分项评分的联合学习

**研究问题：** 同时预测目标完成度与姿态约束等分项，是否能帮助总体评分，并提供可核验的解释？

**数据依据：** KIMORE 原论文定义 cTS、cPO、cCF，值得检查多输出建模；MobiPhysio 有理疗师评分，但文件与参与者清单尚未核实。FineRehab 的完整性、正确性和平滑性标签设计可作参考，不过截至 2026-11-06 官方页仍写即将发布，不能作为确定的数据依赖。

**相关工作：** [KIMORE](https://doi.org/10.1109/TNSRE.2019.2923060)、[评分用 GCN](https://doi.org/10.1109/TNSRE.2022.3150392)、[专家知识图模型](https://doi.org/10.1109/TNSRE.2024.3400790)、[层次对比回归](https://doi.org/10.1109/TNSRE.2024.3523906)。

**最小可检验实验：** 固定临床评分定义和尺度，比较训练均值预测、几何特征回归、轻量时序模型、单总分输出和共享编码器多分项输出。按人测试，报告 MAE、RMSE、Spearman 相关与每个动作/人的误差；不能只凭相关性高就认定预测误差小。

**可形成的贡献候选：** 分项监督的价值；标签稀少时多任务是否有益；不同动作共享编码器是否发生负迁移。

**启动前核对：** 原始问卷是整段多次重复的评分；确认每个文件的评分粒度、范围和缩放，不能切片后把相同总分当作独立逐次/逐帧真值。**收缩条件：** 实际缺少可用分项标签时，先做总分预测；没有纵向真值时，不以预测分数宣称临床恢复趋势。

### 方向 4：有限标注下的多动作预训练与迁移

**研究问题：** 使用公开动作序列预训练共享编码器，是否能在更少的目标标签下提高分类或评分？源动作与目标动作不一致时，何时出现负迁移？

**数据依据：** 可用源和目标取决于解析结果，例如多动作 IRDS 到评分目标；KERAAL 的未标注记录也提供半监督动机。跨数据集关节拓扑、采样和标签语义不同，需要先对齐。

**相关工作：** [ReCon](https://doi.org/10.1007/s11517-024-03177-x) 已有多动作对比学习与 IRDS 向 KIMORE 迁移，作者代码在 [shamarkus/ReCon](https://github.com/shamarkus/ReCon)。因此“加对比学习”或“IRDS 迁移 KIMORE”不构成独立的新意。

**最小可检验实验：** 对比相同目标架构的从零训练、监督预训练、自监督或半监督预训练；冻结/微调策略分开报告。在训练受试者内部按人减少可用标签，绘制标签量与测试表现的关系；例如 10%、25%、50%、100% 是候选预算，需依人数与类别覆盖调整。重复抽取训练标签，避免一次随机抽样决定结论。

**协议要点：** 预训练也不能偷用外层测试人的无标签数据，除非明确研究并单列传导式设置。源目标可能重叠的受试者、重复或数据整理版本要先去重。

**启动前核对：** 可取得的源/目标文件、关节映射和目标标签。**收缩条件：** 预训练始终没有超过匹配训练预算的从零训练时，报告负结果与适用范围，不以增加预训练计算量掩盖对照。

### 方向 5：姿态估计误差下的动作评估鲁棒性

**研究问题：** 从 RGB 提取的骨架误差会怎样影响质量模型？训练时加入置信度或现实噪声，是否能使模型更接近在真实估计骨架上的表现？

**数据依据：** REHAB24-6 原始存储库有双视角 RGB、2D/3D 骨架和正确性标签，适合先核查配对与同步。UL-RED 有 marker 与无 marker 数据，可辅助研究传感器/速度变化，但本轮未确认其有独立质量评分，不能直接充当主质量测试集。

**相关工作：** [VI-Net](https://doi.org/10.3390/s20185258) 研究跨视角；[REHAB24-6](https://doi.org/10.1007/978-3-031-75823-2_2) 提供姿态估计场景；[真实卒中 webcam 研究](https://doi.org/10.3389/fmed.2025.1645369) 显示跨人补偿检测受到表示误差限制，但其数据未确认公开。

**最小可检验实验：** 同一分组划分、同一质量网络，对比动捕骨架、RGB 估计骨架和训练噪声增强，分别报告不同视角与姿态误差区间的分类表现。双视角的同一次动作必须处于同一划分；对姿态误差的统计应按配对动作进行。

**可形成的贡献候选：** 置信度感知的时序建模；从配对数据估计更现实的噪声；质量标签是否被姿态估计失败误导。人工噪声效果不能替代真实估计骨架测试。

**启动前核对：** 相机坐标、投影与同步、公开视频权限、可复现姿态提取。**收缩条件：** 对齐无法可靠完成时，先研究已有骨架质量评估，不把不可靠的配对当真值。

### 如何比较这些路线

| 判断条件 | 应看到的具体证据 |
|---|---|
| 真的可以开始训练 | 至少一批公开文件取得并成功解析，标签和人物清单清楚 |
| 目标可以独立验证 | 输出与人工标签/评分对应，代理标签的生成和局限写清楚 |
| 有足够独立测试单位 | 按人统计每类/评分覆盖，不以大量重复替代独立受试者 |
| 对已有工作有明确问题 | 全文比较后写出可证伪假设及相应对照，不能只列网络名 |
| FYP 可交付 | 主任务可缩小，能保存权重、配置、预测和可复查结果 |

建议先推进“候选数据实际可解析”与“代表方法全文补读”，再选择一条主任务和一个改进问题。训练配置到那时再决定批大小、序列长度与模型规模；现阶段不预设硬件门槛。

供思考的重点是：最终最想让模型回答的是**“做得对不对”**、**“具体错在哪里”**，还是**“质量是多少”**？三者的监督证据和实验设计不同。也可以先用正确性任务验证训练管线，再根据其他数据取得情况选择更合适的最终任务，这不意味着提前锁定 IRDS。
