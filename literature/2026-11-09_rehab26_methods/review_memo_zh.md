# REHAB26 同数据集论文与处理方法核查

调研日期：2026-11-09。针对本项目 REHAB26-ViewAngles 的肩外展（ex1）、肩后伸（ex7）效果不佳问题。完成原始论文全文阅读、PDF 表 1/表 3 渲染核对、官方数据元数据与本地特征代码对照。用户随后提供 P3 出版商 PDF，已补充全文与结果表核查；没有启动新训练。

## 结论

**已找到完全相同数据集的原始方法论文。它首先提示我们重新检查二维/三维表示、临床特征、动作阶段与视角，再讨论进一步的 Transformer 调参。它没有提供与本项目同任务、同划分的五错误宏 F1 基准。**

截至本次检索，OpenAlex 精确检索、REHAB26 宽检索与前向引用中，能确认的同数据集方法论文是数据集作者的原始论文；尚未核实到独立团队的后续同数据集实验。这个结论受索引延迟、名称变体和部分服务访问失败影响，不能解释成“绝对没有其他论文”。

前一轮大规模调参前，我们应该先把这篇原始方法论文的处理方式与自己的任务逐项对照。已有训练仍是可复查的跨人基线，但仅靠训练超参数搜索，无法检验输入姿态质量和任务设置上的差异。

### P3 全文带来的补充

P3 使用独立动捕真值监督上游 HRNet/MHFormer，跨人二维肩外展误差可从 16 降至 7 像素（表 7，horizontal 相机）；相同动作的跨相机测试却从 32 升至 39 像素（表 8）。这支持把上游适配与拍摄条件泛化分开验证，不能把微调视为普遍收益。该数据没有肩后伸，也不能把当前 REHAB26 的 MediaPipe 估计当作动捕真值。

## 原论文到底解决什么问题

P1 第 4.1、5.1 节研究的是：**给定同一个人的几个正确动作，某个姿态表示和相机视角，能否保留足以区分已标注错误的运动特征。**

| 维度 | P1 原论文 | 当前 Transformer v2 |
|---|---|---|
| 用户先验 | 每人、每动作、每录制位置/朝向建立参考；通常 5 次正确动作 | 测试受试者未参与训练，不提供该人的正确参考 |
| 表示 | 2D 或 3D，提取与错误对应的运动学特征 | 单目 MediaPipe world 3D，19 关节坐标与 12 个几何特征，部分配置加入 visibility |
| 时间处理 | 一个动作特征驱动 DTW，与参考动作对齐 | 整次动作线性重采样到 96 帧 |
| 评分 | 相对个体正确轨迹的逐帧容差偏差 | 学习五个错误标签的 logits，BCE 训练，sigmoid 后按验证阈值判断 |
| 评价时是否已知错误类型 | **是：第 5.1 节用真实错误注释选择该次动作应评价的相关特征** | 否：同时预测五类错误，保留附加错误 |
| 指标 | separability，记作 Ψ；并非准确率、AP 或 F1 | 五错误 macro-F1、macro-AP、正确动作误警率、错误动作无警率 |
| 视角比较 | 同视角个体模型、视角偏移实验、选择相机条件 | 多视角观察统一纳入跨人评估 |
| 证据性质 | 姿态表示和观察视角的诊断实验 | 跨人多标签分类基线，五人探索性实验 |

因此，不能把原文“提升 16.9%”“提升 13.1%”解读为比我们的 F1 高这么多，也不能把 Ψ=0.66 写成“66% 分类准确率”。

### 个体化算法的可复现部分

依据第 4.1 节、公式 (1)–(3)，PDF 第 10–11 页：

1. 从当前序列的正确重复中随机选一个参考动作。
2. 用能覆盖动作全幅度的单个特征做 DTW，例如肩外展 F5，将其余正确动作对齐到参考。
3. 对每个参考时刻、每个特征估计均值 μ 和容差 τ。τ 来自 Student-t 分布的 95% 均值置信区间半宽，另设第一四分位数相关的宽度下界。
4. 对待评估动作做参考对齐。偏差未超过 τ 时得分 0；超出时，得分为 `min(1, (abs(F-μ)-τ)/τ)`。
5. 时间平均得到一个特征的动作错误分数 E。
6. Ψ = 错误动作的 E − 建模用正确动作的平均 E。按真实错误类别对应的特征聚合，得到视角/动作层面的可分性。

必须保留的实现边界：

- 第一四分位数究竟对哪一层分布取值，原文叙述不够明确；不能假装已经得到完全一致的容差实现。
- 表 1 给出角度涉及的身体部位，没有完整的 landmark 索引、顶点顺序、符号、投影平面映射和代码。本轮没有验证到作者公开的完整实现。
- 均值置信区间不是新一次动作的统计预测区间。这是作者采用的工程容差，不能直接宣称覆盖 95% 正确动作。
- 原指标中的正确动作也用于构造参考。若将方法用于实际误警评估，校准动作与正确测试动作必须分开；可额外做正确重复的留一校准诊断。
- 若复现个体模板并输出五种错误，必须在推理时计算全部相关特征，不能用真实错误标签挑出“应该看的”特征。原论文的 Ψ 诊断可作为独立复现项保留。

## 可以直接借鉴的处理方式

### 1. 单目 3D 不是必然优于 2D

P1 第 4.3、5.2 节比较了 MediaPipe 2D/3D，并用 YOLO26 交叉检查二维视角结论。作者认为深度误差可能抵消三维表示的优势。

表 3（PDF 第 17 页）经渲染核对的行内最佳值如下，**这些是不同视角上的最大 Ψ，仅描述表格，不是匹配同一视角的受控效应估计，也不是 F1**：

| 本地动作 | MediaPipe 单视角 2D 最佳 Ψ | MediaPipe 单视角 3D 最佳 Ψ | 两正交 2D 最佳 Ψ |
|---|---:|---:|---:|
| ex1 肩外展 | 0.66，15° | 0.59，30° | 0.66，Cam1 -30° 或 0° |
| ex7 肩后伸 | 0.61，10° | 0.65，30° | 0.76，Cam1 -20° |
| ex6 深蹲 | 0.56，-60° | 0.49，-10° | 0.62，Cam1 -40° |

对我们的启示是**按动作验证二维与三维**：肩外展优先查 3D 特征噪声，肩后伸仍保留 3D 对照。原文并不支持“所有动作都换 2D 一定更好”。

本地 `2d.npy` 的 x/y 近似归一化图像坐标，官方页面却写 pixels。必须先确认图像宽高和坐标定义，才能计算保持比例的二维角度；不能分别把 x/y 当同一长度单位直接做几何，也不能把 2D 文件的 z 当成真正的第三维。已有审计中的这个问题尚未解决。

### 2. 专用特征比“几个泛用角度”更贴近错误定义

对照表 1（PDF 第 7 页）和本地 `experiments/rehab26_v1/pipeline.py::angles`；v2 复用这些特征。

| 错误/几何 | 原文特征描述 | 我们现在的实现 | 后续验证重点 |
|---|---|---|---|
| 耸肩 F2 | 双肩与髋部的角度 | 肩线的垂直分量得到肩线倾斜 | 不是同一测量；躯干侧倾可能混淆。核验肩-肩-髋定义，加入对躯干的相对关系 |
| 头部侧倾 F3 | 头、躯干与垂直方向 | 耳线与肩线夹角 | 不是同一特征；比较对躯干、对重力/图像竖直的两种参照 |
| 手臂前移 F1 | 手、肩、躯干关系 | 上臂方向与肩/躯干法向点积 | 上臂与手位置不同；应保留手腕/肘的关系并检查矢状面分量 |
| 手臂位置 F5 | 手与双肩的角度 | 肩角、上臂横向分量等泛用指标 | 复核是否能明确刻画外展峰值不足和后伸时外偏 |
| 屈肘 F4/F8 | 额状面/侧面分别描述上臂与前臂 | 单个三维肘角 | 投影平面及可见性可能影响误差；分别验证 |
| 躯干 F6/F7 | 躯干与下肢；头/躯干/下身旋转关系 | 躯干对竖直夹角、肩线相机 yaw | 区分全身朝向和躯干相对骨盆旋转；不能直接用相机 yaw 代替代偿旋转 |

注意：当前模型还接收原始坐标，因此这些特征差异不是已经证实的性能瓶颈，只是明确可测试的表示差异。原论文 F6 的文字“lateral torso bending”与本地 ex7 `ERR_TORSO_FORWARD` 并不逐字一致；不能机械复制特征到标签映射。

### 3. 归一化需要保留错误信号

P1 对 3D 先将髋部方向对齐到 x 轴，再按特征选择 xy/yz/xz 投影平面；当前实现只有髋平移、整次动作的躯干长度缩放，没有旋转对齐。

可测试消除全身朝向的髋部 yaw 对齐，同时保留肩相对骨盆的旋转、躯干相对重力的倾斜。不能用逐帧完整躯干坐标系把待检测的前倾、侧倾或旋转一起消掉。归一化属于特征定义的一部分，先以构造姿态检查几何含义，再进入模型训练。

### 4. 动作阶段和峰值错误可能被平均稀释

P1 第 5.2 节特别指出，外展幅度不足常只发生在动作顶点，整次动作平均后分数偏低。DTW 可以对齐阶段，但过度灵活的对齐也可能隐藏异常时序，不能当作自动改善器。

后续可分别比较：固定重采样；限制路径范围的 DTW；上举/顶点/回落阶段统计；峰值、上分位数或 top-k 时间聚合。峰值区间必须由运动轨迹定义，不能依据真实错误帧或测试标签选择。以上是我们的后续假设，尚无新实测收益。

### 5. 相机条件先作为实验因素控制

P1 给出的跨模型共识单视角为：肩外展 15°、肩后伸 20°、深蹲 30°。它们不一定等于每一行的最优值，例如肩后伸 MediaPipe 2D 的表内最大值在 10°。第 5.2 节报告参考与测试朝向偏移约 5–10° 时相对稳定，超过约 15° 后多个特征明显退化。

这些角度是该数据与该个体模板协议下的经验值，不是可直接承诺给新患者的最优摆位。先核对官方 `-o / 45-o / 90-o` 的角度符号和论文图示，再预注册宽视角区间。使用论文从同一数据选出的角度属于数据知情的探索，不能当成独立验证。

报告所有视角与固定允许视角应分开，同时报告覆盖率/被排除观察数量；不能只保留“容易视角”再把成绩描述成全视角提升。

### 6. 双视图优先做可解释特征组合

第 4.4、5.3 节的 orthogonal 2D 是**每个特征预先指定更适合的相机**，不是直接拼接两个视频或盲目平均三维关节。作者报告相对其选定单视角条件的 Ψ 改善：肩外展 0%、肩后伸 26.6%、深蹲 12.7%；平均约 13.1%。这些引用值不能统一用表中各行舍入后的最大值重新计算。

三维 visibility² 加权融合和 RUMPL 结果不稳定。RUMPL 是在合成 AMASS 姿态上训练的双视图姿态提升 Transformer，不是在 REHAB26 五人上训练的五错误分类网络，不能作为“别人同数据集 Transformer 很强”的证据。

目前多相机序列总长度不同，虽可能是末尾截断，尚不足以证明所有动作可逐帧无误融合。先核验同步与物理动作 ID，再考虑双视图。不能把同一次动作不同相机当作独立的训练/测试样本。

## 下一轮实验建议：先分解原因，再增加网络复杂度

| 顺序 | 实验 | 必须固定的对照 | 回答的问题 |
|---|---|---|---|
| E0 | 2D 坐标比例、朝向符号、标签-特征对应与局部轨迹检查 | 原始文件和标注不改写，记录每个未决假设 | 几何含义是否正确；先排除表示错误 |
| E1 | 2D 专用临床特征 vs 当前 3D 几何；加入髋 yaw 对齐的平面 3D | 相同人划分、标签、阈值选择规则；先用 LR/RF | 问题主要来自表示，还是网络容量 |
| E2 | 固定 96 帧 vs DTW/阶段统计；均值 vs 峰值/分位数 | 一次只变一个时间因素，使用相同特征 | 短暂顶点错误是否被稀释 |
| E3 | 所有视角 vs 预定义允许视角；按错误、按人、按视角分层 | 报告覆盖率与全视角结果，不根据测试挑角度 | 模型是否在不可观测视角被迫猜测 |
| E4 | 个体正确参考 + DTW + 容差评分 | 作为独立“需要校准”的任务；校准正确动作和测试查询分开 | 少量受试者个体校准能否降低误警 |
| E5 | 把经过验证的特征输入 TCN/小 Transformer | 共享 E1–E3 的输入、划分、计算预算与验证规则 | 在输入有效时，学习时序是否进一步有用 |
| E6 | 两正交 2D 的按特征组合 | 先核对同步，按物理动作分组；视图选择只由训练/验证决定 | 肩后伸是否受益于互补观察 |

这轮不建议先扩大网络、扫描更多激活函数或引入更复杂损失。原论文的主要证据涉及表示、参考和视角，没有证明某个 BCE 替代损失能解决当前问题。原有训练标准化、验证早停与多标签 logits/BCE 流程继续作为对照；新增变量逐项验证。

冷启动跨人结果与个体校准结果分开报告。前者不使用测试人的正确样本；后者明确给定校准预算及允许的视角/会话信息。两者都不能在推理时读取错误标签。由于五名受试者和既有测试结果都已经参与研究探索，新一轮仍应标为探索性结果；确认结论需要新受试者或独立兼容数据。

评价至少保留五错误 macro-AP、macro-F1、逐类结果、正确动作误警率、错误动作无警率、逐人结果和视角覆盖率。统计分析以受试者为主要独立单位，不把三个相机观察算成三名独立患者。

## 数据与原文不一致处

- 论文动作编号 Ex1/Ex2/Ex3 对应本地 **ex1/ex7/ex6**，不是 ex1/ex2/ex3。
- 论文第 3.3 节写 1650 次，官方当前 CSV/元数据为 1665 次。本项目固定实际 CSV 与哈希，不为凑论文计数删 15 条。
- 官方 2D 单位表述和数值尺度不一致；本轮文献阅读没有解决这个数据语义问题。
- RUMPL 段落写 MediaPipe 原生 25 点，而发布数组是 33 点。不能照此猜测索引。
- 表 1 的特征定义、四分位数容差和一些平面选择缺少足够细节，后续实现需显式声明我们的选择及敏感性，不能叫作逐项精确复现。
- 仅五名志愿者、模拟错误，不等同真实患者康复效果验证。

GitHub 有同名候选 `jakeryderv/rehab26`，但 README 请求失败/限流，未确认为作者代码，也未作为方法证据。REHAB24 的第三方工程不自动算论文复现。arXiv:2611.02929 使用 Fit3D，已通过全文确认并排除出“同数据集”集合。Bing 返回无关结果，Google/DDG 访问失败，Semantic Scholar 429，部分出版平台 403/超时；没有将这些失败计为“搜索后不存在”。

- `papers.json`：论文、关系与证据层级登记。
- `source_manifest.json`：来源 URL、下载文件大小/哈希与失败说明。
- `fetch_round3.json` 至 `fetch_round5.json`：本轮后续请求的实际时间戳与响应记录。
- `collect_sources.py`：可复查的关键来源重新采集工具，默认不联网；通过 `--fetch` 显式执行。
- `sources/`：本地官方页面、PDF、提取文本及渲染页；按既有规则忽略第三方全文，不提交全文。

本次修改是文献与下一轮实验设计记录；原始数据、v2 冻结选择、权重、预测和成绩没有修改。当前不能报告任何由这些建议带来的新性能提升。
