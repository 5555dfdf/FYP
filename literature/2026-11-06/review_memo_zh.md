# 公开数据集上的康复动作模型训练：扩大调研记录

日期：2026-11-06。当前阶段：扩展文献与比较训练任务，**未最终定题、未训练模型**。

## 1. 当前目标与对早期判断的修正

用户希望最终尽可能基于公开数据集实际训练出一个模型。本轮明确采用“先广泛比较，暂不限定任务或身体部位”的范围；训练配置暂不确定。

2026-10-17 的工作证明了 IRDS 骨架可读取、标签可用于整体正确性分类，也提出肩前屈作为较有数据支持的切入点。但这些证据不足以证明肩前屈就是最合适的 FYP 主方向。现在把它保留为候选，不继续围绕它提前固定动作、架构或研究标题。

最终成果应尽量包括：可追溯的公开数据版本、明确的预测目标、可复现训练过程、训练后的模型权重、对新受试者的测试结果，以及能够调用模型的推理示例。模型可以从现有架构训练，也可以迁移学习/微调；是否需要从头设计新网络，要由文献缺口和对照实验决定。

## 2. 这轮实际做了什么

- 建立 33 篇核心候选登记：4 篇综述、10 篇数据集或数据相关方法、15 篇模型方法、3 篇基准/评价、1 篇真实应用可行性研究。它们包含此前已涉及的文献，**不是 33 篇全新的全文精读成果**。
- 通过 Europe PMC、Crossref、CVF/IJCAI、作者项目页与 GitHub 获取摘要、书目信息、公开全文和资源说明；保存了原始返回。检索截至 2026-11-06。
- 重点核对数据标签、评分来源、跨人划分、样本版本与可获取性。PDF 的关键评分页面已渲染查看，包括 KIMORE 问卷和 FineRehab 标注段落。
- 正式区分“全文重点核对”“摘要核对”“元数据/官方说明核对”。全文重点核对指已查看与选题相关的标签、方法及实验段落，不意味着已逐公式复现、复算全部结果或完成代码审计。
- 未下载全部候选数据，未运行所列训练代码，也未把文献成绩当作本项目实验成绩。

检索是目的性扩大筛选与引用追踪，不是预注册的系统综述。初始关键词中 MIRA 有大量同名噪声；部分查询出现连接失败，后续改用精确题名、数据名和引用链。原始失败记录保留，不能用原始命中数冒充最终纳入数量。

阅读登记见 [论文比较表](paper_matrix_zh.md)；标签与获取状态见 [数据比较](dataset_comparison_zh.md)。

## 3. 先比较预测任务，再比较网络

| 候选预测任务 | 输入与输出示例 | 需要什么监督标签 | 有依据的数据候选 | 训练研究可以比较什么 |
|---|---|---|---|---|
| 整次动作正确性 | 骨架/视频序列 → 正确/错误概率 | 每次动作的正确性 | IRDS、UI-PRMD、REHAB24-6；部分整理版 | 轻量时序与骨架网络、错误召回、小样本、姿态噪声鲁棒性 |
| 具体错误类别 | 动作 → 错误类别，必要时多个错误 | 对应错误类型、可能含部位/时间 | KERAAL；UCDHE 待追溯 | 多类或多标签建模、类别不平衡、少标注学习、可验证反馈 |
| 连续质量或分项评分 | 动作 → 总分/分项分数 | 专家评分或清楚定义的独立分项标签 | KIMORE、MobiPhysio；FineRehab 获取待定 | 回归、多任务评分、序数模型、跨动作共享、置信度 |
| 动作识别、重复分割或计数 | 连续动作 → 动作类别/边界/次数 | 类别、片段边界或重复标注 | UL-RED、REHAB24-6 等 | 分割、速度变化、辅助预训练；这是独立任务，不直接证明质量评估能力 |

这些是待比较的任务，不是现在承诺同时完成的四个模块。主任务最终只需有足够清楚的输入、标签和测试证据；额外模块必须证明对主任务有帮助。

## 4. 对选题最有影响的阅读记录

### R01 / R02 / R03 / R04：综述如何帮助扩大范围

R01（2020）梳理离散评分、规则、模板与机器学习路线；本轮核对到摘要，全文获取未成功。R02（2023）专门讨论骨架康复动作的特征学习、评价和反馈；本轮也只到摘要，应该优先补读全文。

R03（2025）已经查看全文的纳入研究、数据和评价讨论：该综述在其特定深度相机筛选条件下纳入 18 项研究，不代表全领域只有 18 篇。它反映出自建小数据、真实场景验证和泛化不足的问题。R04（2024）扩大到下肢、视觉、可穿戴与压力感知，说明没有必要因为已有 IRDS 就把课题锁在上肢。

这四篇适合建立问题地图，但综述的二手描述不能替代数据集原文与文件检查。

### D02：KIMORE——评分任务应纳入比较

原论文为 78 名参与者、5 类动作，既有健康人也有功能障碍者。医生用 10 项 EAAQ 评价一整段练习：前三项涉及主要动作目标，后七项涉及身体部位姿态，形成 cTS、cPO、cCF。

对我们的意义：可以研究一个输出总分或多个分项分数的模型，且已有许多方法论文可作为对照。但必须核对标签文件和评分范围：后续论文有 0–50、0–100 等不同目标，不能直接混用。问卷针对包含全部重复的练习，切成多个重复后沿用同一总分属于弱标签，不能当成专家逐次评分。

取得原始骨架和评分文件之前，也不能断言它比 IRDS 更适合。RGB 在原论文中有单独申请和 EULA 条件。

### D04 / M15：KERAAL——错误反馈不必完全依赖自行补标签

D04（IJCNN 2024）给出 3 个低背痛康复动作、12 名患者和 9 名健康人的数据。除整体正确性外，部分数据标有错误类别、出错部位和时间窗，且大量患者记录没有标注。已查看原文的分组、标注及基线段落，并核对作者仓库说明。

这使具体错误分类、部位/时间定位以及少标注学习有真实的数据动机。但总记录 2,622 不等于有 2,622 条完整监督样本；论文和仓库的细项计数、标注者说明存在差异，应该从文件清单核实。

M15（ICORR 2025）的摘要明确用 KERAAL 训练基于 Transformer 的错误分类模型，并计算关节重要性。需要补读全文和查代码，尤其检查按人划分、每类样本数、是否多个错误可同时存在。关节重要性是否准确定位错误，还需要使用对应真值验证。

### D05：FineRehab——标签有吸引力，可获取性尚不满足主数据条件

CVPRW 2024 原文描述 50 人、16 动作、4,215 次动作，以及完整性、正确性/代偿和平滑性三个维度的 0–4 评分；专家给出维度与身体部位权重，生成总体质量分数。已查看原文的数据、标注、方法与实验段落。

它的任务设计比只做二分类丰富。但本次打开官方项目页，下载部分仍写“will be released soon”，没有核实到可下载完整数据。因而它目前适合作为标注与方法参考，不能作为已经确定可训练的主数据源。

还有两个阅读要点：第 4.1 节写 ICC=0.784、95% CI=(0.878, 0.958)，点估计落在区间之外，PDF 图像核对确认是原文如此，应保留疑问；第 5.1 节明确按人划分用于动作识别，不能因此自动认定第 5.2 节所有质量评估实验使用完全相同的协议。

### D09：REHAB24-6——原始存储库确认有质量标签

这篇题名强调姿态估计，初看容易遗漏它的质量评估用途。原始 Zenodo 元数据明确列出 10 人、6 动作、65 长记录、1,072 次重复，以及起止帧、正确性、方向和光照信息。文件清单有双视角 RGB、二维/三维关节和标注。

因此它可以进入下一轮数据解析，比较直接骨架输入与从 RGB 估计骨架的性能、视角和姿态误差的影响。它的受试者和模拟错误性质需要保留，不能当作真实患者队列。原论文全文尚待取得；本轮证据是原始存储库及元数据，不冒充全文阅读。

### M01 / M04：早期评分模型与 EGCN——必须追溯训练目标

M01（2020，摘要核对）以自编码器/GMM 建立表现指标，再映射为评分并用深度网络预测。这说明公开骨架可以训练评分模型，也说明预测一个构造分数与预测独立医生评分不同。

M04（IJCAI 2022，已取得 7 页原文）探索位置与朝向的多种融合。原文第 4.3 节写按受试者五折划分；但第 4.1 节对 KIMORE 把专家与患者分别作为正常与异常代理标签。其预测目标包含人群假设，不能等同于 IRDS 的逐次人工正确性。原文专家人数表述也与 KIMORE 原始人群说明不一致，复现应查样本清单。

可借鉴的是双流特征、融合层级和按人评估，不能直接搬用它的 KIMORE 标签定义去声称学会动作纠错。作者仓库已定位并核对 README，未运行。

### M03 / M06 / M10 / M14：骨架图模型代表

M03（2022）把 ST-GCN 用于连续评分；M06（2023）结合图卷积、GRU 与 Transformer；M10（2024）引入专家知识图、门控池化与时间建模；这三项本轮主要核对摘要，适合后续全文深读。

M14（2025，全文重点核对）通过邻近/远端节点和逐帧拓扑，再融合多尺度时间信息预测分数。但本轮查看的实验说明没有足够清楚地交代按人划分，不能把其指标直接拿来与跨人基准排名。其结构可以提供问题线索，实际效果仍需统一数据和划分复现。

这些方法说明骨架网络有结构优势；它们没有证明“加一个更复杂模块一定优于简单时序模型”。

### M08：LightPRA——轻量模型也应纳入基线

2024 年论文摘要明确聚焦 TCN 的评分能力与计算效率，使用 UI-PRMD、KIMORE。已找到作者名下的模型代码仓库，README 只作简短说明，没有完成依赖、加载器和训练入口审查。

我们可以比较时序卷积、GRU、骨架图模型的效果与复杂度。配置尚未确定，因此现在只记录参数量、输入长度与训练成本，不提前承诺某个模型可以在某块硬件实时运行。

### M07 / M11 / M12：对比学习与迁移——有先例，也有可检验问题

M07（2023，摘要）研究对比学习生成评分并利用关节注意力差异；M12（2024 在线，摘要）结合位置与角度表示，为回归设计层次对比学习。

M11（2024 在线、2025 卷期，全文与作者 README 重点核对）使用同动作正确样本为正对、同动作正确/错误为困难负对、跨动作为较容易负对，训练共享 ST-GCN 表示；并研究 IRDS 预训练向 KIMORE 评分迁移。

这给“基于公开数据训练一个模型”提供了具体路线：多动作训练共享编码器，再微调目标任务。它也意味着“用对比学习”或“IRDS 迁移到 KIMORE”本身不是新的研究缺口。新的研究问题应更具体，例如：减少目标标签时是否仍有益、跨动作不匹配时是否负迁移、按人测试下是否保留增益。

原文主表沿用 Zheng 的 3:1 划分，不能把接近 99% 的分类值当成未见患者泛化。作者当前 README 也没有完整复述论文全部 IRDS 实验，定位到仓库不等于已经可一键复现。

### B01 / B02 / B03：评价协议会改变我们对模型优劣的判断

B01 的详细预印本与官方代码提供 39 分类、21 回归任务，比较九种网络，并明确受试者互斥。任务数来自多个原数据按动作/目标拆分，不是 60 个独立采集项目。它给出了直接训练单个数据、单折、单模型的入口，适合参考实验组织。

预印本采用五次随机初始化的预测集成，主文结果不应直接与我们未来单次训练比较。KIMORE 整理版只有 71 人，而原论文是 78 人；用整理版必须记录筛选与标签定义。论文的全局平均重采样长度等处理也应在加载器中检查；新实验尽量只用训练部分决定数据驱动参数。

B02 在 IRDS 上对传统特征与 ST-SkelNet 使用嵌套按人评价，说明总准确率和错误召回会明显不同；本轮查看了全文相关段落，但未审计实现。B03 的摘要直接研究按样本/按人划分的差异，应补读全文。我们应该自己固定协议，避免从不同论文最高分拼排行榜。

### C01：真实患者 RGB 研究帮助判断部署难点

2025 年 webcam 补偿检测研究使用 20 名卒中参与者，比较 MediaPipe、手工运动特征和光学动捕。文章报告个体内效果明显高于跨人效果。已查看方法、限制和数据可用性声明。

它说明训练后的质量模型能否接到普通摄像头，仍取决于姿态估计误差与人群覆盖。该文声明数据尚未直接公开，不能当作本项目马上可以下载的训练集。可以借鉴它的验证问题，不把未经核实的数据纳入训练承诺。

## 5. 三条待验证的训练研究路线

| 路线 | 要训练的模型 | 数据依据 | 需要先验证的关键点 | 可能形成的研究问题 |
|---|---|---|---|---|
| A：正确性/错误类型 | 时序或骨架分类模型，输出错误概率或类别 | IRDS、REHAB24-6、KERAAL；UCDHE 待查 | 样本清单、独立错误受试者数、错误类别是否稳定 | 跨人错误识别、类别不平衡、噪声鲁棒性或少标注学习 |
| B：总体/分项质量评分 | 回归、序数或多输出模型 | KIMORE、MobiPhysio；FineRehab 获取未定 | 原始评分与缩放、标注粒度、分项可得性 | 共享表示能否同时提高总分和分项评分；小样本评分稳定性 |
| C：多动作预训练与迁移 | 共享编码器，先监督/自监督预训练，再微调质量目标 | 需要至少一个可得的源数据与一个标签合适的目标数据 | 关节映射、标签语义、动作重合、人物/视频去重 | 有限标签时迁移是否有益，哪些动作或传感器差异导致负迁移 |

C 更接近一种训练策略，可以服务 A 或 B；它不要求最后一定部署三个模型，也不代表要把不同标签直接混在一起训练。若不同数据没有兼容真值，应分别预训练/微调或使用任务特定输出头。

目前不对三条路线作最终排名。先以“标签与目标匹配、数据可取得、可复现按人评价、能提出可检验的问题”筛选，再考虑模型规模与设备。

## 6. 下一轮阅读与数据工作顺序

**先补齐直接影响能否训练的证据：**

1. KIMORE：取得骨架与 ClinicalAssessment 样本，核对完整练习/重复的关系、cTS/cPO/cCF 范围与实际人数。
2. KERAAL：读取文件与标注规范，按人、动作、错误类别统计监督样本；查 Group1a/1b 与其他组，处理计数不一致。
3. REHAB24-6：取得小标注和骨架样本，核对 1,072 次重复的标签、双视角同步与 ID；补读原论文。
4. UCDHE：取得原方法全文及错误标签定义。MobiPhysio：核对 Dataverse 实际参与者/评分清单后决定是否提升优先级。
5. FineRehab：保留论文与项目记录；未确认公开文件前，不把训练计划依赖于它。

**方法全文优先读 M03、M08、M15、R02，再深入 M07/M12/M10。** 每篇记录：输入、目标、损失、训练数据、预处理、受试者划分、模型选择、指标、代码及可复用模块。先核对任务是否一致，再看指标。

代表代码检查优先考虑 [DeepRehabPile](https://github.com/MSD-IRIMAS/DeepRehabPile)、[ReCon](https://github.com/shamarkus/ReCon)、[EGCN](https://github.com/bruceyo/EGCN)；先查加载器、训练/验证/测试人 ID 和标签生成，不急于整套启动全部实验。

当两个左右的候选数据已可解析、代表方法的任务和评价已弄清楚，就可以做小规模基线训练，验证文献判断。文献阅读与这一可行性实验可以交错进行，避免无限检索但始终没有训练成果。

## 7. 进入正式训练前应形成的具体产物

- 固定版本的数据清单：subject、exercise、sequence、label、modality、source version、split。
- 一个主预测目标及清楚的标签来源；不预先固定身体部位。
- 至少一个简单可训练基线与一个代表学习/骨架模型；如果研究迁移，另含从零训练对照。
- 同一套受试者分组测试和训练内部模型选择；所有同人重复、视角、增广与切片按协议约束。
- 半监督/自监督预训练也遵守外层受试者划分；除非明确研究并单列传导式设定，不用测试受试者的无标签数据训练模型。
- 分类报告 macro-F1、balanced accuracy、各错误召回/precision 与混淆矩阵；评分报告 MAE、RMSE、相关性以及按人/动作表现。
- 模型权重、配置、随机种子、环境、训练日志和推理入口。再根据实测性能与缺口确定研究标题和改进点。

本轮完成的是扩大调研和证据梳理，正式训练仍未开始。原有 IRDS 数据审计仍有价值，但现在服务于更广的比较，而不是预先决定整个 FYP 的方向。
